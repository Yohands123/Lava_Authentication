# Phase 7 staging/release gate

**NO-GO for production ML or deployment.** Local engineering and synthetic tests do not supply genuine-human validation or independent assurance.

1. Agree on consent, retention, withdrawal, study supervision, permitted devices/environments and independent participant recruitment. Preserve optional participation and accessible authentication. No recruitment is initiated by this document.
2. Preregister matched human/scripted acquisition, takeover, assistive and virtual/remote-browser conditions. Freeze participant/device/family/run/replay groups before comparisons. Provide sufficient independent people and a powered uncertainty/multiplicity plan; retries are correlated.
3. Evaluate behavior/response ablations and environment/source/cadence/shuffled controls with training-only preprocessing and separate calibration. Keep prospective final cohorts untouched until explicit independent review. Never tune thresholds to final results or select an application winner from synthetic fixtures.
4. Commission independent protocol, passkey, registry/withdrawal, accessibility and privacy review. Test real authenticators and physical touch/pen/assistive devices, low-end hardware and abandonment. Resolve external slow-stream behavior in the actual approved serving path.
5. Review an observation-only, hash-pinned candidate and its data/model cards, calibration limits, revocations, runtime budgets and MODEL OFF drill. No remote/pickle loader or automatic promotion. Human FPR/calibration/generalization must support any later access policy proposal independently.
6. Request explicit owner approval for a concrete isolated staging deployment, credentials/resources, spend cap and bounded load plan. Default production guard/ML/Lab/metrics remain off. Measure actual Worker/DO CPU, cold starts, queueing, storage, tails, overload and recovery; local results are not edge capacity.
7. Review sharding/migration only after authoritative routing, global abuse bounds, one-use equivalence, user/credential discovery, revocation and rollback tests are complete. The Node prototype is not an approved cutover.
8. Make a separate explicit release decision. No push, PR, merge, deployment, monitoring, model enforcement or paid-agent use is automatic. Phase 6 creates none of these approvals.

Reproduction starts with [the handoff](LAVAGUARD_PHASE6_HANDOFF.md), [threat model](LAVAGUARD_PHASE6_THREAT_MODEL.md) and machine-readable readiness. Remaining gaps are empirical/independent/operational gates, not missing evidence to be replaced by more invented fixtures.
