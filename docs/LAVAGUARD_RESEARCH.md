# LavaGuard research notes

Inspected 2026-10-17. Source README/license hashes and the pinned training archive are recorded in `ml/datasets/manifest.json`. No research paper's accuracy is presented as LavaGuard accuracy.

| Primary source | Finding and implementation consequence |
| --- | --- |
| [Balabit challenge](https://github.com/balabit/Mouse-Dynamics-Challenge) | Human remote-desktop sessions; simulated impostors are other humans. Never relabel them bots. Repository data license is unclear, so no corpus ingestion. |
| [SapiMouse repository](https://github.com/margitantal68/sapimouse), [author's raw-data page](https://ms.sapientia.ro/~manyi/sapimouse/sapimouse.html) | Authentication sessions across participant devices. The original raw ZIP link was verified on the author's page. No clear raw-data license was found; only source metadata inspected. |
| [BeCAPTCHA-Mouse](https://github.com/BiDAlab/BeCAPTCHA-Mouse), [paper](https://arxiv.org/abs/2005.00890) | Studies function-based and GAN trajectories, including neuromotor features. Download requires an institutional agreement. No restricted data downloaded, no agreement signed, no email sent. |
| [DELBOT-Mouse](https://github.com/chrisgdt/DELBOT-Mouse), [MIT license](https://github.com/chrisgdt/DELBOT-Mouse/blob/master/LICENSE.md) | Small labeled research corpus with natural mouse motion, pyhm, pynput and GAN families. Used locally with pinned revision, retained attribution, no raw redistribution, and explicit task/device/identity limitations. |
| [Ghost Cursor](https://github.com/Xetera/ghost-cursor) | Public synthetic cursor generator. Tested as its own seeded family; curved movement alone is insufficient bot evidence. |
| [Playwright input](https://playwright.dev/docs/input), [Puppeteer Mouse](https://pptr.dev/api/puppeteer.mouse) | Browser automation controls cursor input through the browser. Tested separately from DOM `dispatchEvent`. Browser-originated trusted events are not proof of a human operator. |
| [DOM specification: trusted events](https://dom.spec.whatwg.org/#dom-event-istrusted) | `isTrusted` distinguishes event dispatch mechanisms, not a human identity or secure attestation. Client claims about it remain forgeable. |
| [Fitts, 1954](https://doi.org/10.1037/h0055392) | Movement duration depends on target distance and width. Speeds and corrections must be interpreted within task and device context. No universal speed threshold proves automation. |
| [Mouse parameter configuration research](https://github.com/micemicsresearch/mouse-dynamics-data-credibility) | Acquisition configuration changes observed dynamics. No new raw corpus ingested; sampling/downsampling and source leakage remain explicit evaluation limitations. |

The local generator suite covers linear, fixed-speed circles, random, cubic Bézier, variable-speed curves, overshoot/correction patterns and a lognormal-shaped speed proxy. The lognormal proxy is not a validated sigma-lognormal neuromotor implementation. Ghost Cursor and Puppeteer run as actual libraries. DOM synthetic events, malformed telemetry, timestamp edits, replay, direct endpoints and concurrent redemption are covered independently.

Human movement may be slow, fast, smooth, shaky, precise, assistive, touch or trackpad input. No absent pressure field or smoothness-only feature is punitive. Feature extraction reports distributions and corrections; it does not estimate a persistent identity. Bubble metrics need consenting application-specific studies, which have not occurred.

The offline experiment fits logistic and forest baselines, and an Isolation Forest on human training rows only. Logistic scores receive sigmoid calibration on separate source folders. Human device folders and unfamiliar generator families are held out. Participant identifiers are unavailable, so this cannot establish a user-disjoint trial; source/task leakage remains possible. Group-level metrics, Brier scores, confusion counts and Wilson human-acceptance intervals are exported. These corpus results do not justify production enforcement.

The initial passing-preview correction enabled localhost model rejection; the owner subsequently reported four human retries while manually controlling that test browser. Current ordinary preview disables model rejection and keeps browser/movement hints advisory. A WebDriver context does not identify who is moving its pointer. Isolated research tests still verify actual model FLAG decisions, including with the hint masked. Phase 2 leave-one-family-out, cadence matching and calibration experiments demonstrate poor generalization; see `LAVAGUARD_PHASE2_RESULTS.md`. Production activation remains disabled and no consenting application-human acceptance trial is claimed.

Evidence is deliberately weak when client features are the only signal. A scripted caller can submit plausible aggregates. Browser raw paths would also be forgeable, and uploading them would violate the existing privacy promise. The protocol therefore enforces scoped issuance, nonces, expiry, one-time redemption and rate controls, with verified passkeys providing identity authentication. No behavioral cryptographic attestation is claimed.
